## Изменения фазы 4

### Новые методы кластеризации

Добавлено 6 новых методов кластеризации в директорию `ClusteringMethods/`:

1. **WaveClustering** (`WaveClusteringAlgorithm.py`)
   - Кластеризация на основе вейвлет-преобразования
   - Поддержка многомасштабного анализа данных
   - Параметры: размер сетки, тип вейвлета, количество уровней разложения, порог плотности
   - Зависимости: PyWavelets, scipy

2. **BallTree Hierarchical Clustering** (`BallTreeClustering.py`)
   - Иерархическая кластеризация с использованием BallTree структуры данных
   - Поддержка различных метрик расстояния (евклидова, манхэттенская, Чебышёва)
   - Методы linkage: ward, complete, average, single
   - Зависимости: scikit-learn, scipy

3. **HPStream Clustering** (`HPStreamClasteringAlgorithm.py`)
   - Проекционная кластеризация для высокомерных потоковых данных
   - Автоматический выбор значимых размерностей
   - Поддержка инкрементального обучения через скользящее окно
   - Зависимости: scikit-learn

4. **VP-Tree Bregman Divergence Clustering** (`VPTreeClustering.py`)
   - Кластеризация на основе VP-tree с поддержкой различных дивергенций
   - Поддержка дивергенций: евклидова, Хеллингера, Бхаттачарьи
   - Метрики: манхэттенская, Чебышёва, косинусная
   - Реализация без зависимости от pyBregman (использует только scipy)
   - Зависимости: scikit-learn, scipy

5. **KMeans с опциональной PCA** (`KMeansClustering.py`)
   - Реализация KMeans из scikit-learn с возможностью предварительной PCA декомпозиции
   - Поддержка различных методов инициализации (k-means++, random)
   - Настраиваемое количество инициализаций и итераций
   - Зависимости: scikit-learn

6. **MiniBatchKMeans** (`MiniBatchKMeansClustering.py`)
   - Оптимизированная версия KMeans для больших наборов данных
   - Обработка данных батчами для снижения потребления памяти
   - Поддержка опциональной PCA декомпозиции
   - Зависимости: scikit-learn
